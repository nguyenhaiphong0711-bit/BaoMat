# LearnSpace – tài liệu thuyết trình

## Bản mới nên sử dụng

- `LearnSpace_Final_Professional.pptx`: 30 slide, theme học thuật tối giản, nền trắng và tương phản cao.
- `LearnSpace_Final_Professional.pdf`: bản xem dự phòng giữ đúng bố cục và màu sắc.
- `LearnSpace_TaiLieu_HocVaScript.docx`: tài liệu học và lời thuyết trình đầy đủ.
- `LearnSpace_TaiLieu_HocVaScript.md`: bản chữ nhẹ, mở trực tiếp trên GitHub.

Bài trình bày giới thiệu dự án, nghiệp vụ và chức năng theo Admin/Staff/Teacher/Student, sau đó trình bày kiến trúc hệ thống và các cơ chế bảo mật đã triển khai: authentication, authorization, data scope, cookie, BCrypt, OTP, CSRF, XSS, NoSQL Injection, GridFS, kiểm duyệt, quiz snapshot, audit, rate limit, backup và dependency scan.
